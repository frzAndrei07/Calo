# Ingredients:
Single piece of food, with its own calories and macros
Can either, add one to your personal pool of ingredients, or use the general ones
General ingredients are added in automatically, whenever someone using the app registers a new ingredient, it gets run in the database to see if there is a row with a product name that partially equals to the one manually created. If there are no matches, the api is called, to check if the data introduced is coherent. if not, then the item does not get created in the general pool || Are added by the system, and only the system.
Each ingredient has its own calories and macros.
An ingredient has:
 - * Name (user input)
 - * Calories per 100g (manually ?OR AI?)
 - Macros per 100g (manually ?OR AI?)
 - * State (cooked or raw)
When creating an ingredient, the user has to type each * field, and macros could be generated by ai

# Dish
Its an array of 1 or more ingredients.
When creating a dish, you have to select all the ingredients of the dish.
When selecting the ingredients, you can choose ingredients by, typing in a <input>, and below it, a <select> drops down, matching the ingredients name with:
 - Your ingredients
 - General ingredients
 - Option ingredients. You indicate the calories and macros of the ingredient at the time of creating a dish, which is not mandatory to be saved
For each ingredient, you have in troduce the weight. 
If its your ingredient, you can also edit the info of that ingredient in that dish. When editing, you can also save the changes made to that ingredient to save it to your account.
Upon creating, the total amount of calories and macros are calculated. ?Also an estimate cal/100g is calculated?
The dish also has the posibility to be weighed in raw, and also, to be given the total cooked weight, to get the estimated cal/100g cooked.
